Food Delivery App

A full‑stack food delivery platform built using ASP.NET Core, Razor Pages, and C#. The application includes dynamic menu rendering, category filtering, item detail pages, and a fully interactive cart system. Users can browse meals, adjust quantities, view real‑time pricing updates, and simulate checkout with accurate subtotal, tax, and total calculations.

The backend is powered by SQL Server with structured tables for menu items, categories, orders, and cart sessions. Data is retrieved and updated through Entity Framework Core with clean, maintainable Razor Page handlers. The UI is built with Bootstrap for responsive layouts and jQuery/DataTables for fast, interactive filtering and sorting.

The app also includes form validation, error handling, and a mock payment workflow modeled after Stripe API patterns. Designed with modular components, separation of concerns, and production‑style architecture to mirror real delivery platforms.
Tech Stack:
- ASP.NET Core · Razor Pages · C# · SQL Server · Stripe API · Bootstrap · jQuery · DataTables
